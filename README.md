# Personal Expense Tracker

A simple command-line expense tracking application built with Java. The program allows users to record personal expenses, organize them by category, view saved expenses, and calculate total spending.

## Features

- Add a new expense
- Store the expense name, category, and amount
- View all recorded expenses
- Calculate total spending
- Menu-driven command-line interface
- Object-oriented Java structure

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Git
- GitHub
- Visual Studio Code

## How It Works

The project is divided into three main Java classes:

**Expense.java**  
Represents an individual expense and stores its name, category, and amount.

**ExpenseTracker.java**  
Manages the collection of expenses and calculates total spending.

**Main.java**  
Provides the command-line menu and handles user interaction.
